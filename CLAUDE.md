# IM HOLZ CZ — новый сайт imholz.cz

Пользователь не разработчик: объяснять просто, делать самому, идти пошагово. Язык общения: русский. Язык сайта: чешский (потом EN и DE).

## План
1. Статический сайт (HTML/CSS/JS, без сборки) на чешском — **здесь**.
2. Перенос на WordPress + Oxygen (по образцу imholz.at; готовый HTML заливается через `html-to-page`, CSS-префикс `bb-`).
3. Остальные языки через WPML.

## Дизайн-система
Полностью повторяет imholz.at (репозиторий `pkhoriakova-prog/im-holz-nova-vscode`). Не изобретать новый стиль.
- BEM с префиксом `bb-`: `bb-block__head`, `bb-card--catalog`. Новые компоненты строятся на тех же токенах из `:root` в `css/styles.css`, новый CSS добавляется в раздел «IM HOLZ CZ» в конце файла.
- Шрифт Manrope, зелёный `#014335`, тёплый серый фон `--paper-warm`, линейки листа (`bb-sheet-rules`, `*__ground`), плоские квадратные карточки с hairline-рамкой, без теней и скруглений.
- Ссылки-действия только `bb-link-underline` (с буквенной анимацией, JS делит текст по буквам). Заголовок в карточке — `bb-heading--card`, текст — `bb-copy--card`.
- Секции: `bb-section` + `bb-block` (метка слева `bb-section-label`, заголовок от первой линейки `bb-block__head`). Серые секции — с `bb-section__ground`.
- Адаптив: точки 1150, 1080 (меню), 640. Проверять на 1440 и 600 px (headless Chrome не рендерит уже 500).
- Иконки: `images/icons/` (взяты из imholz.at), логотипы: `images/logos/logo-green.svg`, `logo-white.svg` (инлайн-SVG со старого imholz.cz).

## Ритм страницы
**Фоны строго чередуются, два одинаковых подряд нельзя** (требование пользователя): белый hero → серый «Příběh» с цифрами (цифры только на сером) → белый «Katalog» (серые карточки с штриховкой) → серый «Výhody» (Service Cycle с зелёной панелью) → белый «Služby» (серые карточки со штриховкой) → серый «Poptávka» (слева список фактов в стиле «Message from the Founder»: Společnost, Adresa, E-mail, Telefon, Pracovní doba, IČO; справа форма без белой карточки) → зелёный футер. **Размеры меток и текстов под заголовками одинаковые во всех секциях (как на imholz.at), «подписи побольше» означало больше ТЕКСТА, а не больший шрифт.**

## Единая форма запроса
Расстояния формы берутся только из токенов (`--gap-label-title` метка→поле, `--gap-para` поле→поле, `--gap-text-link` до кнопки, `--gap-title-text` внутри плашки), метки полей = метка секции (`--label-fs`, .16em, капс). Блок «Poptávka»: слева контакты в стиле списка фактов из «Message from the Founder» (`bb-contact__facts`: E-mail, Telefon, Adresa; линии короче, как на imholz.at), справа форма **без белой карточки** прямо на сером фоне, главная (`#request-form`), позже та же на `poptavka.html`. Форма лежит на плашке с фоном в тонкую штриховку (белый + диагональная штриховка, рамка). **Одна форма без шагов и нумерации** (пользователь убрал деление 01/02): поля 2×2 (имя*, фирма*, e-mail*, телефон) → поле-кнопка «Co vás zajímá» (список направлений свёрнут и открывается панелью с «Hotovo» и «Vymazat výběr»; итог «Vybráno: N oblastí» и строки выбранного; внутри «Nevím přesně, poraďte mi», направление → группы → плитки до последней позиции из схемы каталога) → «Zpráva» → согласие со ссылкой прямо в тексте → чёрная кнопка «Odeslat poptávku». Принципы полей: подпись сверху (капс с трекингом, как метки сайта), плоский белый бокс, зелёная линия снизу при фокусе, ошибки по-чешски рядом с полем, цели нажатия ≥44 px. Выбор копится в скрытом поле `souhrn`. Форма пока **не отправляет** данные (пометка «testovací verze»); при переносе на WordPress подключить форму Oxygen и e-mail. Списки материалов предварительные. Не усложнять.

## Вкладка браузера и SEO-шапка (как на imholz.at)
- Значок: `images/identity/site-icon.png` (зелёный круглый знак, тот же что на imholz.at), `<link rel="icon">` + `apple-touch-icon` в каждой странице.
- **SEO-правила (пользователь просит SEO-дружелюбность).** Один `<h1>` на странице, с ключевыми словами: сейчас «Velkoobchod s řezivem a dřevěnými materiály od nosných konstrukcí po pelety». Ключи для чешского рынка: velkoobchod, řezivo, dřevěné materiály, KVH, BSH, CLT, pelety. Иерархия заголовков строго h1 → h2 (заголовок секции) → h3 (карточка); метки секций `bb-section-label` — это `<p>`, не заголовок.
- `<title>`: ключевая фраза, затем бренд: `Velkoobchod s řezivem a dřevěnými materiály | IM HOLZ`; внутренние страницы `Řezivo: smrk, borovice, modřín | IM HOLZ`. Каждой странице свой `<title>` (до ~60 знаков), `meta description` (до ~155), `og:*`, осмысленные `alt` у фото (с ключами), `width`/`height` у всех `<img>`.
- Все картинки сайта только в AVIF (без JPG/PNG-копий; фавиконки и SVG не трогаем): ≤2000 px (hero), ≤1200 px (карточки), `avifenc -q 55 -s 4` (для рисунков с прозрачностью `-q 60 --qalpha 80`). Кодировщик libavif 1.4.2 скачивается во временную папку, правило в `.claude/settings.local.json`. JSON-LD `Organization` в `<head>` главной (телефон, адрес, email добавить после подтверждения).
- **При запуске:** убрать noindex, добавить canonical, hreflang cs/en/de, sitemap.xml и robots.txt.
- Пока сайт — черновик, на **каждой** странице стоит `<meta name="robots" content="noindex, nofollow">`. Убрать при запуске, не раньше.
